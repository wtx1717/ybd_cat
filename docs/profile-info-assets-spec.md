# 个人信息栏素材生成规格

参考图：`概念图-白天.png`

参考图原始尺寸：`3840 x 2160`

本文档只描述首页左上角个人信息栏相关素材。生成结果需要在像素风、比例、边框厚度、材质、颜色和装饰细节上尽量贴近概念图，不替换顶部导航、地图背景或其它模块素材。

## 总体要求

- 个人信息栏在概念图中的参考区域约为：`x=108, y=252, w=690, h=870`。
- 所有素材按 `1x` 原图像素尺寸生成，禁止先生成小图再放大。
- 风格为精致像素风木质/羊皮纸 UI，边缘有深棕木框、金色角件、浅米色纸面和轻微内阴影。
- 素材应支持透明背景，除明确说明为不透明底图的资源外，统一导出为 PNG。
- 文本不烘焙进图片，除非素材本身是图标或装饰。文字由前端渲染。
- 需要和原图高度一致：整卡高度按 `870px` 生成，内部头像区、标签区、统计区、底部按钮区按下表尺寸控制。

## 布局尺寸基准

以下尺寸用于保证生成素材和概念图保持一致。坐标均相对 `profile-card-frame.png` 左上角。

| 区域 | 坐标与尺寸 | 要求 |
|---|---:|---|
| 外卡片 | `0, 0, 690, 870` | 木质边框厚约 `10-14px`，内纸面留边约 `36px` |
| 头像框 | `58, 86, 214, 286` | 青绿色内底，深棕双层边框，四角小金属钉/暗角 |
| 标题区 | `318, 92, 300, 72` | 标题右侧预留 `42 x 42` 爪印图标位 |
| 身份行 | `318, 190, 300, 34` | 文案为前端文字，底图不含字 |
| 简介区 | `318, 282, 300, 120` | 保持浅纸面，无额外边框 |
| 标签区 | `58, 456, 574, 62` | 4 个标签同一行，间距约 `18px` |
| 统计区 | `58, 570, 580, 228` | 4 行列表，每行高约 `52-56px`，分割线要轻 |
| 底部按钮 | `58, 812, 580, 58` | 在 `870px` 卡片内底部居中，按钮素材自身为 `580 x 58` |

注意：底部按钮在概念图中贴近卡片底部，生成 `profile-card-frame.png` 时需要预留底部按钮空间，不要让统计区压到底。

## 视觉要求

- 边框：深棕木质像素边，局部有金色角件，高光不要过度平滑。
- 纸面：浅米色羊皮纸，允许轻微颗粒、边缘暗角和内阴影。
- 头像框：内底为低饱和青绿色，边框比标签和统计区更重。
- 技能标签：浅棕按钮质感，圆角很小，不能现代化，不要玻璃拟态。
- 统计区：浅米色半透明底，边框和分割线要弱于外框。
- 图标：统计图标需像素化，颜色和概念图一致，大小统一为 `32 x 32`。
- 底部按钮：无强烈实心底色，像概念图一样是纸面上的文字入口，右侧箭头简洁。

以下内容由前端渲染，不应烘焙进素材：

- 名称：`云边的云`
- 身份：`代码工匠 · 跑者 · 猫奴`
- 简介：`喜欢把想法变成可运行的东西，也喜欢把跑步变成习惯。`

- 底部入口：`了解更多关于我`

## 导出要求

- 格式：PNG。
- 色彩：sRGB。
- 缩放：1x 原始像素。
- 命名：严格使用上表文件名。
- 背景：除 `profile-card-frame.png` 内部纸面外，其它素材外部区域保持透明。
- 像素边缘：保留硬边像素感，不要使用过度柔化的 AI 插画边缘。
