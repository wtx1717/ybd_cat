参考原图：`概念图-白天.png`，尺寸 `3840 x 2160`。本清单只覆盖底部信息概览区域，包括左侧可点击书本、底部横向概览条、三块信息面板及其装饰图标。所有尺寸均按原图 1x 设计稿标注，生成素材需要和原图像素风格、透视、颜色、边框厚度保持高度一致。

## 生成要求

- 输出格式：透明背景 PNG，保留硬边像素感，不使用现代扁平矢量风。
- 画风：与原图一致的精致像素游戏 UI，暖色羊皮纸、深棕描边、金属角件、轻微纸张纹理。
- 线条：主边框约 `4-8px`，内部装饰线约 `2-4px`，不要出现细到 1px 的现代 UI 线。
- 光影：使用原图同方向的柔和高光和暗部，书本与面板底部要有轻微接触阴影。
- 颜色：棕色、金色、米色、墨绿色为主，红色书签作为强调色；避免新增紫色、蓝紫渐变或玻璃拟态效果。
- 文本：图片素材中除 `overview-book-label.png` 不应烘焙具体中文内容，实际文字由前端渲染。
- 拉伸：面板背景、进度条底和进度条填充必须支持横向拉伸，四角和边框不可变形。
- 一致性：同一批素材的视角、描边粗细、颗粒密度、阴影强度必须统一，不能混用不同模型风格。

## 验收标准

- 在 `3840 x 2160` 页面中放置后，左侧书本与底部横向概览条的占位比例应接近概念图。
- 收起概览时，书本素材的位置、大小和倾斜角度保持不变。
- 展开概览时，三块信息面板的高度、边框厚度、分隔柱和角件位置与概念图保持一致。
- 在 `947px` 宽度以上视口中，面板文字不能越界，素材边框不能挤压变形。
